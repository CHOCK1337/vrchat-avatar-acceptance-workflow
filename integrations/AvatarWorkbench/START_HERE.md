# 改模工作台 / Avatar Workbench · 0.2.4

**打开：Unity → Tools → 改模工作台（Avatar Workbench）**。窗口可以停靠或浮动。

1. **选角色：** 在顶部“目标角色”栏选择或拖入完整角色；已在 Hierarchy 选好时点“使用选中角色”。已有 QuickTask 可从“更多 → 选择已有任务”绑定。
2. **挑素材：** 左侧点“挑素材”，用顶部来源下拉选择“本次已选 / 本地素材库 / 百度网盘 / BOOTH 搜索”。本地库的“管理来源”可选择素材目录或读取已有 Mio `library.json`；登记新目录后点“更新列表”。切来源、搜索和浏览使用现有索引，不会自动扫描。图片、色卡和贴图不会被收录为独立安装资源。
3. **看大图：** 点图片或“查看大图”查看名称、店铺、图片与适配提示；路径等信息在“来源与文件信息”中。勾选“选择素材”后点“将所选素材附到需求”。“本次已选”中的“附到需求”直接决定随请求带上的素材；选择和查看都不会立即安装。“3D 预览 / 并排看素材”显示素材自身，尚未适配。
4. **看模型：** “试穿衣服 / 预览姿势 / 角色菜单”只操作临时角色；“视角与聚焦 / 回到全身”只移动相机。左拖旋转、滚轮缩放、右键 + WASD 移动，Q/E 升降、Shift 加速。“预览选项”中有 Unity PhysBone、晃动和结束试穿；缺少可靠接口时禁用。“放大预览”暂时收起输入区，点“完成预览”返回。画面始终区分编辑态、临时试穿和历史图。
5. **发送需求：** 在底部“想怎么修改？”写一句话，点“发送给 Codex”。目标、候选和所选素材自动附上；局部问题先点“圈出问题位置”冻结真实画面并框选。到“看回复”查看实际回应；已发送不代表已读，已回应不代表修复通过。未连接时请求仍保存，可复制继续处理指令或导出。

左侧 **AI 接口**、底部 **发送到** 管理工作台自己的 Codex / API 路由，支持已有 OpenAI 兼容、Anthropic 兼容或自定义服务。API 负责读需求与回复建议；正式 Unity 改模继续由原 Codex 工作流执行。不会改变 Skill、全局模型、MCP、Packages 或上传权限。

百度网盘可保存分享、读取文件列表、加入参考，并关联已下载目录。登录 / 验证码 / 自动下载尚未接入；有效分享成功读取仍需实际链接验收。BOOTH 商品是参考，不证明购买或适配；原图超时会回退并标注缩略图。声明见 [BOOTH_NOTICE.md](BOOTH_NOTICE.md)。

**安装 / 更新：** 在 ZIP 解压目录先运行预览，再更新；只更新 `Assets/AvatarWorkbench`。本地修改会停止并列出需合并的文件，旧反馈、草稿、任务和已有 `.meta` 保留。

```powershell
python install_avatar_workbench.py --project 'D:\你的Unity工程'
python install_avatar_workbench.py --project 'D:\你的Unity工程' --apply
```

接入命令见 [CODEX_CONNECT.md](CODEX_CONNECT.md)，实测与限制见 [VERIFIED.md](VERIFIED.md)。不自动构建或上传。
