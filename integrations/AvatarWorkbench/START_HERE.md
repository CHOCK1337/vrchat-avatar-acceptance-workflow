# 改模工作台 / Avatar Workbench · 0.2.3

**打开：Unity → Tools → 改模工作台（Avatar Workbench）**，Window 菜单也有入口。可停靠或浮动，无需重装 Skill、配置 MCP 或升级 Unity / SDK。

1. 在 Hierarchy 选择完整角色根对象，点“用选中的角色”；也可直接在顶部角色框选择。已有 QuickTask 用“更多 → 选择任务”绑定。真实网格与原材质会显示在模型区；来源条区分编辑态、临时试穿和历史图。
2. 左侧“素材库”有“本次素材 / 读取目录 / 百度网盘 / BOOTH 找素材”。目录页粘贴或选择已下载文件夹，添加后点“读取目录”，再筛选、勾选并加入本次素材；只读该范围，封面和贴图不当安装资源。“3D 预览 / 双素材预览”显示真实 Prefab，拖动旋转、滚轮缩放；这里是**素材自身，未适配**，不安装、不运行作者脚本。
3. 底部“模型”选择当前 Codex 或已保存的 API / 模型。左侧“模型设置”可添加 OpenAI 兼容、Anthropic 兼容或自定义地址，包括 DeepSeek / 本机服务。模型名称可手填或读取真实列表，也可单独指定识图模型。**API 负责读需求、识图和回复建议；正式 Unity 改模仍由原工作流的 Codex 执行。** “需求与回复”内“继续交给原改模流程”会创建保留原候选的新 Codex 请求。
4. 输入一句话即可发送，角色、候选和勾选素材自动附上。指出局部问题时先冻结真实画面、框选，再输入并发送。圈选是图片坐标；旧图不换绑候选，缺少原目标信息时标为未知。只有实际消费者回写才显示已读 / 已回应，答复不代表修复通过。
5. 左侧“截图记录”浏览已有原图和反馈截图。没有前图时禁用对比。普通 970×456 布局保留顶部角色、左侧导航、底部输入和发送，无整页横向滚动；素材与回复在自己的区域内滚动。打开圆盘或“放大预览”会临时收起输入区，点“完成预览”返回。

相机支持左键旋转、中键平移、滚轮缩放，右键 + WASD 移动、Q/E 升降、Shift 加速；“视角 / 聚焦 → 全身”恢复视角。换衣服 / 换姿势 / 圆盘沿用已安装的 Gesture Manager，只操作临时角色；接口缺失或没有处理后候选时显示原因，不临时构建补齐功能。

BOOTH 保留中文转换、独立搜索 API、图片网格及原图超时回退。商品是参考，不证明购买、安装或适配。声明见 [BOOTH_NOTICE.md](BOOTH_NOTICE.md)。

**名称与图片：** “读取目录 → 读取 Mio 素材库”选择已有 `library.json`，只读复用名称、分类、适配标签和图片；也读取同位置已有的包内预览缓存，不启动 Mio 或解压素材。自己的目录读取会关联说明链接、文件夹编号线索与已有图片，排除纹理、色卡和广告；编号线索尚需核对。点击卡片或“详情 / 大图”可翻看图片，已关联商品可按需读取 BOOTH 的真实信息与封面。原图超时会回退并标注缩略图，刷新和重开保留已获取内容；这些信息不证明素材已适配。

**百度网盘：** 粘贴完整分享文本，补提取码、可选名称，点“添加分享 → 读取文件列表”。可进入目录 / 翻页，勾选后“加入本次参考”；提取码只在本机保存，不附到模型请求。管理分享菜单可打开原链接、复制提取码或移除记录。需要登录、验证码、分享失效或网络失败时如实提示。下载请在百度完成，再点“关联下载目录”；自动登录 / 下载尚未接入，有效分享成功读取仍待实际链接验收。

**安装 / 更新：** ZIP 解压后，在安装器目录运行 `python install_avatar_workbench.py --project "你的 Unity 工程"` 先预览，再加 `--apply`。只更新 Assets/AvatarWorkbench，保留已有 .meta、未知本地文件、任务与工程外反馈。代码冲突列出后停止，由 Codex 局部合并；不备份 Library / Temp。

接口配置与密钥保存在工程外，可选 Windows 当前账号加密记住密钥；文本和截图发送范围分开确认。不记住的密钥在脚本重载后消失。不要把密钥写进反馈。未配置 API 可用原 Codex；没有消费者时保留请求，提供复制接手指令和私有导出。
