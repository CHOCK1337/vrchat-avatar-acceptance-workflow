# BOOTH 搜索组件与声明

此目录集成 [wuhutakeoffyoo/booth-cli](https://github.com/wuhutakeoffyoo/booth-cli)，固定提交 `ebfa333b9110d5c0f803a7448035b518fe3d2625`（上游版本 1.5.1，2026-10-02 获取）。
通用元数据修复及原图下载模块已提交至 [上游 PR #6](https://github.com/wuhutakeoffyoo/booth-cli/pull/6)，候选提交 `b55b1a27fbf9750e5d927cbd4b1b6fdddf58eb42`；当前仍待上游合并。该 PR 不含本插件的 GUI 或工作台专用封装。
`booth.py`、`request_budget.py`、`search_evidence.py`、`smart_search.py`、`provider_api.py`、`search_api.py` 源自该提交。上游版权为 Copyright (c) 2026 NyakoWW，按随附 `LICENSE` 的 MIT 许可使用。完整版权及许可文字保留。

Avatar Workbench 的修改及封装：

- `booth.py` 移除年龄确认 Cookie；年龄确认页面返回明确提示；单次 HTTP 正文及解压后读取限制 8 MiB；根据当前实际搜索页补充下一页箭头识别（上游仅识别 `rel="next"`，在 2026-10-02 的实测页面漏报）；保留实际搜索卡的缩略图地址，不还原成原始图片。
- 商品规格沿用上游 `field1` 至 `field6` 组合；这些字段为空时读取接口实际返回的 `name`。该兼容修复基于本地已缓存商品 `7514937` 的原始响应，确保素体版本名称不丢失，不推测适配。
- `workbench_bridge.py` 为本项目封装，仅暴露公开关键词搜索与商品详情。固定全年龄、数字商品、VRChat 标签；最多 3 个检索词，每个词只获取用户指定的一页，交错合并、去重后最多返回 24 项；不自动翻页。保留 BOOTH 6 次 HTTP 请求预算、65 秒截止时间、限流、冷却和缓存，Unity 外层 80 秒强制超时与取消。
- `workbench_query.py` 为本项目新增的文本方案适配：默认本地有限词典，支持常见中文短词和已知素体名称；遇到不支持的完整需求、否定或歧义长句会明确提示改用独立 API 或日文关键词，不伪装为翻译成功。原词模式完全保留输入。
- 独立 API 模式仅调用上游 `smart_search.plan_search` 和 `provider_api` 的文本转换与模型发现，不调用完整 `cmd_smart`、商品 AI 评估、图片分析或网页搜索 API。`pykakasi` 在上游导入时为可选项，本路径不调用它，因此无需新增 Python 依赖。保留上游 HTTPS/端点及重定向限制。
- 对 vendored `smart_search.py` 的局部补丁：规划 JSON 必须提供字符串关键词数组和布尔 `translated`；禁用规划内部的嵌套传输重试（最多两次规划 POST，模型为空时另有一次 `/models` 查询）；单次 API 回复最多读取 2 MB。不会硬编码服务的模型名称，用户填写名称或使用接口公开的模型列表。
- 所有运行缓存和临时文件写入当前 Unity 工程 `Library/AvatarWorkbench/Booth`。不会加载 `.env`、继承环境 API 密钥或读取登录 Cookie。独立 API 配置只由 GUI 经进程 stdin 传入内存，密钥不进入进程参数、环境变量、商品缓存或请求记录；错误和公共结果在输出前脱敏。代码不会将密钥存入磁盘。翻页可仅传已经确认的 `query_plan`，不带配置或密钥，不再次调用服务。
- `WorkbenchBooth.cs` 为本项目的 Unity Editor 异步进程和图片适配，网格缩略图只访问 BOOTH 官方 `booth.pximg.net` 的真实 `300x300_a2_g5` 搜索卡端点，保留 `_base_resized` 文件名，不跟随重定向。早期本地适配产生的 320 像素地址会归一化到已实测成功的官方规格，封面失败保留 HTTP 状态码供诊断。
- 本次新增的通用 `image_download.py` 同样按随附 MIT 许可使用，是本次为上游准备的候选模块，尚不属于上述固定上游提交。`ProductImageAsync` 仅在用户点击大图时调用它：精确读取商品接口 `images[0].original`，不猜测或删除 `_base_resized`；原图下载限时 12 秒，失败后至多一次 10 秒缩略图回退。原图和缩略图合计最多两次并行下载；原图最大 8 MiB、独立缓存最多 64 MiB；禁止重定向，尊重冷却。可终止网络子进程的 stdin 生命周期绑定桥接父进程，窗口关闭/脚本重载取消时不会留下继续下载的孤儿请求。
- Unity 适配只接受 JPEG/PNG，在解码前检查尺寸头（最大单边 8192、总像素 32 Mi），原图格式或尺寸不适合显示时明确回退缩略图。元数据未缓存时，image 动作临时使用 3 秒 HTTP 限时和单次尝试；普通搜索与商品详情请求保持原设置。缓存位置仍在当前工程 `Library/AvatarWorkbench/Booth`，公开商品图片和任何用户素材均不打入插件包。

本功能由 Avatar Workbench 使用社区开源工具提供，与 BOOTH/pixiv、VRChat 及商品作者无官方合作或认证关系。商品名称、图片、说明及素材版权归原权利人。价格、授权条款和适配范围以卖家商品页为准；搜索匹配不代表已验证适配。商品链接和封面仅用于挑选参考，加入需求不代表已购买、获得使用授权或已经安装。请通过卖家正规渠道取得合法授权并遵守使用条款；本功能不提供登录、购买、付费文件下载或绕过访问限制。

搜索会向 BOOTH 发送实际检索关键词与筛选条件，浏览可见卡片时请求官方封面缩略图，点击详情时请求商品说明，点击大图时读取商品接口提供的公开原图。默认本地词典不调用模型。用户主动选择独立 API 并搜索时，仅搜索文字会提交至用户配置的 HTTPS 服务地址，可能产生该服务的费用；认证密钥仅提供给该配置的服务。不会将当前工程路径、角色文件、截图或聊天历史提供给搜索 API，也不读取 BOOTH 登录凭据。此能力与 Codex 会话、全局模型设置相互独立。公开网页及接口可能变化；网络失败或站点限流会如实显示错误。

离线验证覆盖本地词典、上游 API 请求 JSON 序列化、模型发现、鉴权错误脱敏、方案复用、固定筛选和合并限制。没有真实商业 API 凭据，因此商业服务的在线请求尚未验证，不能把离线 mock 结果当作 DeepSeek 在线成功。
