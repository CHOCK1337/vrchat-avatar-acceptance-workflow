# v0.2.0 实测与边界

2026-10-07，在既有 Milfy 工程、Unity 2022.3.22f1 中先预览安装改动，再局部更新 Assets/AvatarWorkbench。实际 Editor 编译成功。以下是本轮实际操作，不以编译或 JSON 解析代替交互验收。

## 已验证

- Tools 菜单打开真实 EditorWindow；970×456 停靠区与浮动窗口可切换模型、素材、回复页签，角色选择、输入及发送留在固定区域，无整页横向滚动。大图素材、模型设置和截图记录在独立原生窗口打开。
- 选择正确角色后显示真实网格、原材质和完整身体。素材画廊显示已有封面或 Unity AssetPreview；同时打开两件衣服的独立真实 Prefab 预览，实际拖动旋转，勾选两件并应用后，需求上下文只带勾选项。这里不是角色适配或安装结果。
- 实际打开 API 设置，读取服务返回的模型列表并保存，再从底部切回当前 Codex。OpenAI 兼容及 Anthropic 兼容请求均在本机协议测试服务完成；Windows 当前账号加密密钥在配置重读后可用。
- 在真实输入框输入“确认收到标记，暂不修改模型”，冻结真实模型图、拖动框选并发送。独立识图请求实际携带原图，文本请求实际读取现有 assemble-vrchat-avatar Skill；API 回复回写原收件箱，明确未执行模型修改。
- 点击真实 API 回复中的“继续交给原改模流程（Codex）”，当前 Codex 桌面会话实际收到新请求，读取原图、原候选、圈选及素材，再回写已读与回应。Unity 显示实际回应。原反馈保留，新请求保留原身份，不把建议当作修复通过。
- 截图记录实际展示既有处理后截图。点击记录返回主预览并关闭记录窗口；历史反馈保留原候选和原图来源，缺少原目标信息时标为未知，不绑定当前角色。
- 关闭素材窗口后，两份自有临时预览场景和渲染资源释放。关闭主窗口时自有预览根对象为零，实际帧纹理已销毁；从正式 Tools 菜单重开后仅恢复一份主预览，未提交文字、冻结图和所选素材恢复。
- 拒绝远端明文 HTTP、带用户信息 / 查询 / 片段的接口地址；更换地址后不能复用旧加密密钥。反馈公开模型身份不包含接口根地址或密钥。请求关闭、超时或回执未知不自动重试。

选中角色时，既有 VRChat SDK 检查器曾自动初始化 Descriptor 并标脏场景；已重新打开原已保存场景，没有保存该变化。最终场景干净。原候选、正式场景 / 材质 / Prefab、任务、Packages、Skill 和已有 .meta 进行文件保护核对；旧反馈保留，仅本轮测试请求写入了自己的状态。安装器保留未知本地文件，遇到代码冲突在写入前停止。

实际 Unity 窗口截图在私有交付目录，不进入公开 PR 或插件 ZIP。公开包只含 Editor 源码、文档、安装器和第三方许可，不含付费模型、截图、任务、反馈、缓存或密钥。

## 未实现或未重新验收

- **独立 API 自动执行 Unity 改模尚未实现。** 本版可选模型、识图、回复建议，然后交回当前 Codex，实际改模仍用现有 Skill。没有复制 Mio 的自动改模引擎或新增后台 Agent 平台。
- 本机服务只验证协议与数据流，不是商业 AI。DeepSeek、OpenAI、Anthropic 等外部接口的实际认证、推理质量和视觉能力没有用户凭据，尚未验证；模型列表也不证明识图能力。
- 素材预览仅显示素材自身，不运行作者脚本，不证明兼容、安装、穿模修复或 NDMF 构建通过。没有网格、未导入的安装包或无法独立显示的资源会说明原因。
- 原有右键加 WASD、Q/E、Shift、Gesture Manager 原生圆盘 / 姿势和动态预览沿用 v0.1.9。本轮未重新遍历全部菜单或做完整 PhysBone 验收；既有 BOOTH 搜索、原图超时回退也未重复做联网验收。
- 未验证其他 Unity / SDK / Gesture Manager 版本。工程里既有 NonToon 重复菜单警告未改动；本轮工作台没有编译错误。
- 未运行构建、Build & Test、上传或客户端验收；没有新增上传按钮、自动购买或已购文件下载。
