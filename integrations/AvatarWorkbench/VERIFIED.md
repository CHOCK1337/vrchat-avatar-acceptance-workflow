# v0.2.4 原生界面实测

2026-10-07，当前既有工程、Unity 2022.3.22f1。安装器先预览再更新；本轮中间版本只在哈希核对后局部合并。以下由实际 Unity 窗口操作与截图确认。

- 导航改为“看模型 / 挑素材 / 看回复”；AI 接口与目标角色区分。来源、当前目录、搜索和更新在一行，移除原目录侧栏和多排读取入口。素材大图卡片可直接打开原生 UI Toolkit 详情窗口，多张已有图片分别标注来源。
- 真实 970×456 停靠区中，目标角色、素材图、搜索、大图、选择、固定输入和发送入口可见，无整页横向滚动。实际搜索“樱花”并恢复完整图库；图库来自既有真实索引。
- 实际打开换装菜单，发现旧菜单被按钮宽度截断并修正。加宽后完整显示穿搭名称；通过真实菜单试穿另一个现有衣服，结束试穿后恢复现场画面。临时角色完整可见，场景始终没有脏标记；未改 Avatar 或共享材质。
- 实际关闭工作台，`AW_Cover`、`AW_PreviewRoot / AW_GestureAvatar` 和 `AW_FrozenFrame` 都为 0。通过真实 Tools 菜单重开浮动窗口，目标和未发送文字恢复；随后停靠到原 Scene 区域继续验证。
- 在固定输入区输入“确认收到界面标记，暂不修改模型”，实际点击发送；当前 Codex 收到并读取原文件、原候选和原选定素材，回写 seen / addressed。“看回复”显示同一请求的真实回应；`execution_started=false`，不代表改模修复通过。
- 编译成功；必要原生操作期间未出现新版工作台编译、USS 或运行异常。源码、安装文件、清单和 ZIP 一致，保留既有 `.meta`、旧反馈、任务、正式模型、原素材、Mio 数据库和配置。

本轮范围为界面整理，原预览、物理、反馈、BOOTH 和来源读取能力沿用已有实现。没有新增自动购买、账号登录、下载、上传或新的改模执行器。有效百度分享成功读取、其他 Unity 版本及全部第三方角色的菜单兼容性仍未验证。使用者是否满意这版视觉效果需实际验收。

实际窗口截图另行私下交付，不包含在公开插件源码包或 PR 中。

# v0.2.3 实测与边界

2026-10-07，既有 Milfy 工程、Unity 2022.3.22f1。安装器先预览，再更新；后续本轮中间版本逐文件核对哈希后局部合并，保留既有 .meta。以下为实际 Unity 原生窗口与本地文件结果，不使用 HTML 演示。

## 0.2.3 本轮已验证

- 修复消费者状态提示只更新一次的问题。另实际发送“确认收到状态更新标记，暂不修改模型”，先回写 seen 并观察原生已读提示，再回写 addressed；同一反馈 ID 的底部提示随回应更新，不把旧等待读取文案留在已回应请求上。

- 在真实文件选择器中选择用户已有的 Mio `library.json`，只读取得 436 个实际素材条目；385 项有可用的已有图片，其中 42 项使用 Mio 已缓存的包内 Unity 预览。436 是工作台按明确商品 ID 得到的条目数，不等同 Mio 自己额外按名称合并后的卡片数。
- 970×456 停靠区域实际展示图片、名称、分类、图片来源、详情按钮和固定需求输入 / 发送。卡片图片在该布局为 104×104；选择、翻页在本机执行。没有整页横向滚动，底部按钮可见。
- 从真实素材卡打开原生“详情 / 大图”窗口，查看本地商品封面。实际点击“读取商品信息与封面”，通过既有 booth-cli 取得 BOOTH 商品 6751976 的名称、店铺及 1024×1024 原图。服务端图片 URL 保持原样，图片来自真实下载，未拼接猜测原图地址。翻到已有本地图片时分别显示来源，旧图缺少来源类型则明确说明。
- 通过真实“读取目录”按钮刷新 Mio 索引，商品名称 / 店铺 / BOOTH 原图继续保留。实际关闭工作台后自有 `AW_Cover` 纹理从 6 降到 0；重开同一 970×456 窗口，目录选择、原图和元数据恢复，没有自动扫描或联网读取。
- 对本次真实选定的樱花光环商品目录只读调用目录适配，正确找到子目录中的 unitypackage、商品上层目录内已有封面和文件夹 BOOTH 编号线索；明确标为 `file_name_hint`，关联尚未确认。另用独立临时契约样本检查不同商品不会共享同名之外的封面、纹理不成为资源；契约样本未进入真实素材库。
- 在原生输入框输入“确认收到素材信息与图片标记，暂不修改模型”并点击发送；当前 Codex 实际收到、读取原反馈、目标、r2 候选与原素材，回写 seen / addressed。本次未附图、未新增素材、未处理模型；反馈接入不代表模型修复通过。
- 当前 Unity 编译成功，正式场景保持干净。交付核对正式 Avatar / 场景 / 材质、任务、Mio 原数据库、Packages、Skill 和既有 .meta；源码与实际安装内容匹配。真实窗口截图单独私有交付，商品图片、数据库、缓存、任务、反馈和密钥不进入公开 ZIP 或 PR。
