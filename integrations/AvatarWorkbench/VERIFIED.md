# v0.2.2 实测与边界

2026-10-07，在既有工程的 Unity 2022.3.22f1 中先运行安装器预览，再更新 Assets/AvatarWorkbench；本轮自身中间版本冲突逐文件核对哈希后局部合并，已有 .meta 保留。以下来自实际 Unity 原生窗口操作。

## 0.2.2 本轮已验证

- 新增“读取目录 / 百度网盘”页，实际 970×456 停靠和浮动布局可操作。目录路径、读取按钮、卡片操作、勾选加入及需求输入 / 发送都在页内；百度页输入、读取、管理和底部按钮可见，没有整页横向滚动。实际发现并修复了路径输入横向挤出按钮、空列表英文提示和小窗口分享操作重叠。
- 通过原生输入框登记本次选定的衣服目录，点击读取后实际遍历 6 个子目录、79 个文件，找到 5 个 Prefab 变体；已有 Unity 缩略图、真实名称和单项 3D 预览可见。只读该范围，图片不当成独立安装资源。
- 实际勾选一件 Prefab 并加入本次素材，GUI 选择 / 上下文增加，正式场景仍干净，原任务没有写入。验收后仅移除测试新增选择，原用户选择保留；目录索引继续可用。
- 通过真实按钮打开目录资源的原材质 3D 预览，界面注明“素材自身，未适配”。关闭素材窗口后没有残留素材窗口，未安装衣服或更改正式 Avatar。
- 通过原生界面输入、保存一个明确标注的无效百度测试链接，再点击读取；实际 HTTP 请求返回 404，窗口显示未能读取，没有生成成功列表、下载或安装状态。测试分享记录及输入已清理，不留作用户素材。
- 从原生标签菜单关闭工作台：自有 Workbench 临时根对象与窗口为零。再从 Tools 菜单重开，目录索引、分享输入和失败记录恢复，来源索引哈希不变，无自动目录扫描或分享请求；浮动窗口也正常。
- 在实际 970×456 区域输入“确认收到目录与百度网盘界面标记，暂不修改模型”，点击发送。当前 Codex 桌面会话实际收到并读取原文件、目标、r2 候选与原素材，回写 seen / addressed；Unity 回复页显示真实文本。本次没有附图，网盘参考为空。修复了实际回应后底部仍显示“等待读取”的旧提示，按发送时的同一反馈 ID 更新。
- 来源 API 实际按需读到目录索引并排除原始分享草稿与提取码；分享 URL 中的提取码、init 链接编号保留及页面静态 JSON 解析完成契约检查。契约样本未显示为真实文件列表。
- 实际 Unity 编译成功、无本轮 Error / Exception、正式场景保持干净。交付前核对正式 Avatar / 场景 / 材质、任务、Packages、Skill 及旧 .meta 哈希，源码与安装内容匹配。私有图片、索引、任务、反馈和密钥不进入公开包或 PR。

## 0.2.1 既有验证记录

2026-10-07，在既有工程、Unity 2022.3.22f1 中先预览安装改动，再局部更新 Assets/AvatarWorkbench。本轮重做界面，未修改渲染、菜单、API、搜索和反馈后端。以下为实际原生窗口操作，编译或 JSON 解析不代替交互验收。

## 本轮已验证

- Tools 菜单打开真实 EditorWindow；实际 970×456 停靠区及浮动窗口显示角色选择、左侧导航、模型区与固定输入 / 发送。素材和回复内部可滚动，无整页横向滚动。没有前图时对比禁用，角色来源仍区分编辑态、处理后候选与历史图。
- 原材质和完整身体可见。用“视角 / 聚焦”菜单聚焦鞋子后再回到全身，正式 Body / Body_base 仍开启，正式场景保持干净。
- 素材库展示已有图片或 Unity AssetPreview，可输入名称过滤、勾选素材并打开真实 3D 预览。修复了 Unity 2022.3 固定高度虚拟列表在窗口不足一行高时不生成卡片的问题；970×456 中实际卡片、名称和操作按钮可见。
- 同时打开两件衣服的独立 Prefab 预览，实际拖动其中一件旋转。这里是素材自身，未安装、未适配；关闭素材窗口后仅保留主窗口的一份临时预览。
- 在新输入框实际输入“确认收到界面标记，暂不修改模型”，冻结真实模型图并拖动框选。关闭主窗口后自有预览根对象为零、实际帧纹理已销毁；从 Tools 菜单重开后恢复未提交文字、冻结图、框选、原候选和所选素材，仅一份主预览，无 Gesture 预览根对象。
- 点击实际发送按钮后，当前 Codex 桌面会话收到请求，读取原反馈文件、原图、圈选、候选及素材上下文，随后回写已读和实际回应。新界面显示“已有回复”与真实文本。回应明确暂不修改模型，不表示模型修复通过；旧反馈仍保留。
- 从左侧打开真实模型设置和截图记录窗口，样式统一；现有接口配置没有变化，截图保留原来源与候选身份。旧反馈、选择和任务继续使用原数据。
- 界面更新前后核对原候选、正式场景 / 材质 / Prefab、任务、Packages、Skill 与已有 .meta；插件安装器先预览、保留未知本地文件，代码冲突在写入前停止。本轮自身界面的中间版本差异经逐文件核对后局部合并。

实际 Unity 窗口截图单独私有交付，不进入公开 PR 或插件 ZIP。公开包仅含 Editor 源码、文档、安装器与许可，不含付费模型、截图、任务、反馈、缓存或密钥。
