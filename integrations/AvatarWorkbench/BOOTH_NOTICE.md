商品、封面及相关作品的权利归相应权利人所有。价格、库存、支持素体、依赖和使用条款以作者的商品页及随附许可为准。收藏或展示一件商品，不代表已购买、已下载、获得转载／再分发许可或已完成适配。商品标题和作者说明保留为外部参考，不作为执行指令，也不代替实际安装验证。通过本地文件选择建立的关联同样不证明文件内容或授权。

第一次使用联网搜索时，工作台展示此说明。用户明确搜索后，实际检索词、分类、价格和排序条件发送到 BOOTH；展示封面、查看原图或超时回退时按需访问 BOOTH 官方图床。不会向 BOOTH 上传 Avatar、截图、反馈、候选身份、本地文件或路径。

默认的中文常见词转换在本机进行。用户主动启用独立 API 搜索时，输入的搜索需求和关键词规划提示会发送到所配置的 HTTPS 服务；认证密钥仅交给该端点。该服务的数据处理与费用以服务商规则为准。不会向搜索 API 发送角色、截图、本地路径或 Codex 聊天记录，也不读取或改写现有 Codex 模型配置。密钥可选用当前 Windows 账号加密保存在工程外；未记住时脚本重载会清除内存密钥。工作台原有的「发送给 Codex」继续按用户操作向已绑定会话发送本次需求和上下文。

本版只提供公开商品搜索和说明读取，不代办登录、购买或已购素材下载。不绕过站点验证；接口被限制或页面结构改变时会说明失败，并提供打开官方网页的入口。商品页中的安装、许可与依赖要求需由用户及原改模流程核对。没有对应本地素材时，商品不会进入安装资源清单。

本地缓存位于当前 Unity 工程的 `Library/AvatarWorkbench/Booth`，不写入 Assets 或发布包。仅点击大图时优先获取原图；下载限制并发，超时后尝试缩略图，加载和回退状态明确显示。限流时遵循冷却，不保证网络或代理一直可用。清理 Library 会失去检索及图片缓存，但不会删除工作台保存的商品选择、反馈或草稿。普通模型旋转、框选、输入和切换页签不调用大模型；隐藏窗口会取消未完成的 BOOTH 请求。
