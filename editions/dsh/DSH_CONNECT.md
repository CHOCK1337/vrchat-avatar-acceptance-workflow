# DSH 接入 · 0.3.5

当前安装入口是 Setup.cmd / Setup.ps1，使用随包便携环境直接接入已有桌面 DSH。不会默认启动额外 Web/隔离 DSH。

完整步骤：[用户手册](docs/USER_GUIDE.md)。工具名、固定接入 ID、配置位置和模板：[MCP 与配置](docs/MCP_AND_CONFIG.md)。故障：[排查手册](docs/TROUBLESHOOTING.md)。

旧版 deploy.py、Install-Runtime.ps1、Start-DSH.ps1 是源码目录中的历史迁移辅助，不是本完整分发包的安装路径。原生 DSH 账号/模型/权限沿用用户配置。
