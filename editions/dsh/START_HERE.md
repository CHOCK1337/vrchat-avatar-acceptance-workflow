# 从这里开始 · 完整包 0.3.5

先看 [README.md](README.md)。普通用户按 [用户手册](docs/USER_GUIDE.md) 安装；DSH Agent 按 [Agent 手册](docs/AGENT_GUIDE.md) 操作。

完整解压后双击 Verify-Package.cmd，再保存关闭 DSH/Unity，运行 Setup.cmd 并输入工程目录。重开 Unity，等编译完成，运行 Doctor.cmd，然后在 DSH 新会话使用 examples/FIRST_TASK.md。

工具包自带便携 Python、Node 和已编译 MCP。已有 DSH 模型账号、Unity 工程及合法 Avatar 素材仍需用户准备。没有自动上传和自动唤醒会话。
