# Codex v0.1.8 发布验证

- Windows 完整包为 `AvatarWorkbench_Codex_Full_v0.1.8_Win64_20261112.zip`，包含 5,743 个清单文件，外部 SHA-256 为 `2e48edf9435cbe8356db0eeadd26024840c3d12dda7136e41940479a202ba632`。
- 全新解压后，用随包 Python 执行严格包校验与隔离回归。ZIP CRC、文件集合和全部文件哈希通过，回归 59 项通过。新增的 5 项测试覆盖旧版空锁自动清理、有内容的旧锁不自动清理、损坏的占用记录、短暂写入争用和占用报错内容，其中 4 项在修复前失败。与上版逐个比对，5,444 个便携运行时文件的哈希相同。私有数据及本机路径的既定扫描无命中。
- 在 Unity 2022.3.22f1 隔离工程中操作真实工作台控件，测试会话模拟 AI 占用：体型选择在脚本重新编译后保留；AI 持有 1 小时占用时点“我来操作”，占用缩短为 60 秒并倒计时，结束后控件恢复；存在旧版空锁时接管成功并自动清理；手动操作期间发送需求自动交回。修复前同样的步骤可以复现问题。
- 在隔离目录放入 codex-v0.1.7 的工作台文件和一个用户文件，用新版安装器预演升级：更新 9 个工作台文件，用户文件保留。
