# Codex 改模执行约定

实际操作以用户当前需求和安装到工程/复用的 `assemble-vrchat-avatar/SKILL.md` 为准。技能本体内的引用可独立使用，不依赖本包所在磁盘盘符。

1. 确认准确工程、Avatar 和当前绑定。旧任务、处理后候选、预览克隆、历史图片分别识别。
2. 确认衣服含真实网格。菜单节点、空辅助 Prefab、成功日志都不能替代穿上衣服。
3. 先做一件可见改动。需要衣柜时验证 A→B→A 与受影响的部件开关，保留作者可用的控制。
4. 腿部问题分别查当前 Mesh、骨骼/权重、姿势、Body 隐藏形态、袜鞋遮罩和实际可见衣片。只修明确原因，不能清空所有形态来掩盖损坏。
5. 持久化编辑用自己的 busy 租约；临时换装/姿势/截图保持 active idle。用真实菜单路径与原图，不靠直接置参冒充操作。
6. 原图真的进入当前模型并被查看后才能记视觉结论。没有图像通路就记 NOT_RUN，并说明缺口。
7. 反馈要先读原记录，再读冻结图片，才能 seen；addressed 仅表示已处理反馈，不表示模型通过验收。
8. 用户授权的当前会话才可以绑定。只发送用户点击发送提交的需求；安装或接入检查不自动生成测试消息。
9. 不改用户全局权限/模型，不擅自换模型或启动其他 Agent，不上传未授权的 Avatar。
10. 交付写明真实候选、实际操作、实际看到的结果和未测项。历史 DSH 案例不能作为新 Codex 会话的通过证据。
