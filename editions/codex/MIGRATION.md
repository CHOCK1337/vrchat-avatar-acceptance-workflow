# 从 DSH 或旧 Codex 接入迁移

本包不卸载 DSH，不改 DSH profile，也不改 Codex 全局配置。可在同一工程保留 DSH/API 设置，使用工作台的“当前 Codex”作为当前执行宿主。

已知发布版本的工作台文件可按 manifest baseline 更新；现有 `.meta` 和未知文件保留，用户修改过的代码发生冲突时停止。已有同名 Skill 原样复用；不要覆盖用户工作流。若要用本包新版，先由用户明确决定旧 Skill 的保留/迁移位置，再重新 Setup。

安装器仅复用可核对的现有 MCP。不同路径的 UnityMCP 需要编译入口内容一致；不兼容或重复注册会报告冲突。不要把删掉全局 MCP 当成默认修复。先查看报告中的位置，选择维护既有连接或明确替换。

安装事务有逐文件备份。关闭目标 Unity 后使用 `Rollback.cmd` 可恢复最近一次写入；保留安装后的用户编辑时，应先按报告处理冲突。回滚不会删除 Unity 生成的额外 `.meta`、空文件夹、任务或反馈。
